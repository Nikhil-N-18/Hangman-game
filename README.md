# Hangman-game

A modern, interactive web-based Hangman game built with HTML, CSS, and JavaScript.

## Features
- **Visual Design**: Ambient background particles, gradient mesh, and sleek glassmorphism UI.
- **Dynamic Gameplay**: Multiple word categories, difficulty levels, and hints.
- **Audio & Animations**: Sound effects and victory confetti celebrations.
- **Comprehensive Word Bank**: Built-in master word database across categories.

## Project Structure
- `index.html`: Main game structure and layout
- `style.css`: Styles, glassmorphic themes, responsive layout, and animations
- `script.js`: Core game logic, state management, and user interaction
- `words.js`: Word list and categories database
- `tools/`: Build and audit utility scripts
